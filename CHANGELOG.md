# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [3.6.1] — 2026-11-02

### Удалено

- **Твик «Автоподстройка окна приема TCP» удалён полностью.** Он выполнял
  `netsh int tcp set global autotuninglevel=disabled` — то есть не включал автонастройку, а
  выключал её, вопреки собственному названию и описанию. На каналах с высоким RTT (любой
  зарубежный CDN или игровой сервер) это упирает приём в потолок окно/RTT: замер на реальной
  машине дал 0.93 МБ/с вместо 22.13 МБ/с до сервера во Франции, и 0.06 вместо 2.34 МБ/с до
  США. Твик убран из интерфейса и из всех пресетов, включая «Max Performance» и «Balance».

### Исправлено

- **Автонастройка окна TCP восстанавливается автоматически.** Если в системе всё ещё стоит
  `disabled` или `restricted`, WCS при запуске возвращает `normal` — лечение получают и те,
  кто уже применил прошлую версию.
- Убран лишний символ в начале этого файла.

## [3.6] — 2026-11-02

Релиз с фокусом на безопасность и предсказуемость изменений.

### Безопасность

- **Мост WebView2 → нативный код теперь проверяет источник сообщений.** Раньше любая страница,
  оказавшаяся в WebView (навигация по ссылке, XSS в тексте релиза), могла вызывать привилегированные
  действия от имени администратора. Добавлена проверка `get_Source()` и блокировка навигации за пределы
  `https://wcs.local/`; новые окна WebView запрещены.
- **Включена проверка TLS-сертификатов** при проверке обновлений и загрузке обложек
  (убраны `INTERNET_FLAG_IGNORE_CERT_*` и `curl -k`).
- **Валидация URL** перед передачей в `curl` и `ShellExecuteW`: только `http(s)`, без кавычек,
  управляющих символов и пробелов — исключает инъекцию аргументов.
- Модальные диалоги скриптов отключены (раньше `confirm()` неявно возвращал `true`).

### Исправлено

- Очередь фоновых задач вместо неограниченного `std::thread(...).detach()` на каждый запрос:
  тяжёлые операции выполняются последовательно, без гонок за реестр и BCD.
- Поток отложенной очистки памяти больше не использует объект окна после его уничтожения
  (join в деструкторе вместо `detach`).
- Ответы с ошибкой теперь содержат `id` — интерфейс больше не «зависает» на ожидании ответа.
- Устранена гонка при инициализации общего окружения WebView2.
- Перечисление автозагрузки больше не обрывается на первом значении длиннее предыдущего.
- 32-битные записи `Run` читаются по правильному пути (устранён двойной `WOW6432Node`),
  состояние `StartupApproved` читается в нативном представлении.
- `LargeSystemCache` больше не включается при отключении твика.
- `PERFBOOSTMODE` при откате возвращается к значению по умолчанию (1), а не к `Aggressive`.
- Блок доменов телеметрии в `hosts` теперь удаляется при отключении (маркеры BEGIN/END),
  путь строится от `%SystemRoot%`, создаётся резервная копия.
- Политика телеметрии Office пишется в версионный ключ `Office\16.0\Common\Privacy`.
- Ключ блокировки Recall исправлен на `WindowsAI` (без пробела), твики Windows 11
  не применяются на Windows 10.
- Очистка журналов событий больше не выгружает `wevtapi.dll`, пока рабочие потоки ещё выполняются,
  и не стирает журнал Security.
- Из «очистки мусора» убраны `Windows.old`, `$Windows.~BT`, `$GetCurrent`, `ESD` — они ломали откат ОС.
- Game Boost снимает повышенный приоритет с процессов при отключении.
- `TCP autotuning` при сбросе возвращается к `normal`, а не к `disabled`.

### Изменено

- README и тексты в интерфейсе больше не обещают «100% безопасность», «100% античит-безопасность»
  и «TLS 1.3»: вместо этого — честный список того, что не откатывается.
- Добавлены таймаут и откат состояния для моста, защита от двойных кликов,
  видимое состояние `disabled`, кольцо фокуса для клавиатуры.

### Удалено

- Модуль лицензирования и привязки к оборудованию (проект распространяется свободно).
- `cloudflare_bot`, скрипты активации и прочая инфраструктура продаж.
